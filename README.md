# IPC・FI改正状況チェック Streamlit版

## 起動

```powershell
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

画面は `IPC` と `FI` のタブに分かれています。各タブは対象ファイル、列設定、処理結果、ダウンロードを独立して保持します。入力ファイルは変更せず、結果は新しい `.xlsx` としてダウンロードします。

## IPC改正情報の管理

特許庁の公式ページ（<https://www.jpo.go.jp/system/patent/gaiyo/bunrui/ipc/ipc7_8.html>）から必要な年度版ZIPをダウンロードし、サイドバーのアップロード欄で複数ファイルをまとめて選択してください。ファイル名が `rcl_202601.zip` の形式なら改正時期を自動入力します。登録前に各改正時期を確認・修正してから、一括登録できます。登録済みの情報は `data/ipc_revisions` に保存され、改正時期、登録元、登録日時、行数を一覧で確認できます。

特許庁のCSVは、改正前バージョン、改正後バージョン、改正前記号、属性1、改正後記号、属性2の6列形式に対応しています。

## 最新IPCファイルの管理

`IPC8_DAT` は拡張子のない固定長テキストとして、サイドバーの「最新IPCファイル」から複数選択できます。アプリはIPC記号、階層、適用期間、状態、番号、説明の6列に変換して保存します。ファイルの更新時期は登録時に入力し、登録済み一覧の「更新時期」で確認できます。既存の更新時期を再登録すると置き換え、新しい更新時期を登録すると既存データを維持したまま追加します。

保存先は `data/latest_ipc` です。同じStreamlitサーバーを利用するユーザーは、登録済みのIPC改正情報と最新IPCファイルを共有できます。

## FI改正情報の管理

FIタブでは、対象FIを含む `.xlsx`、`.xlsm`、`.xls`、または `.csv` をIPCとは別に選択します。FI改正情報はサイドバーの「FI改正情報（XLS）」から登録します。`fi_202601.xls` のようなブックに含まれる次の4シートを読み込みます。

- `新設`: 新FIと新タイトル
- `廃止`: 廃止FI、廃止時移行先FI、新旧タイトル
- `タイトル変更`: 更新FIの新旧タイトル
- `ドット変更`: 更新FIの新旧タイトル

登録済みのFI改正情報は `data/fi_revisions`、FI_DATは `data/latest_fi` に保存され、IPCの共有データとは混在しません。FI結果は1つの一覧で表示され、対象データ、改正時期、改正種別、改正前FI、改正後FI、改正前タイトル、改正後タイトルを確認できます。

FI_DATでは、展開記号や分冊識別記号を含むFI記号（例: `A01B 3/04 A`、`A01B 69/00 303A`）を保持して照合します。

VBAの仕様に合わせて、IPCは先頭4文字を年、`/` より前を4文字にゼロ埋め、`/` より後を6文字に右ゼロ埋めします。形式不正の行は「変換エラー」タブで確認できます。

クラウドで機密データを扱う場合は、公開設定のCommunity Cloudではなく、社内認証とデータ保持方針を満たす環境へ配置してください。
